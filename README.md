# BIO-324: Spatial Firing-Rate Maps

A hands-on tutorial on generating spatial firing-rate maps from spike and position data collected in the laboratory.

## What you will learn

- Position and spike data
- Spatial binning
- Occupancy calculation
- Spike counting
- Spatial firing-rate maps
- Gaussian smoothing

## Prerequisites

No prerequisites are required. Some familiarity with Python is helpful, but prior Python experience is **not mandatory**.

## Example environment

- **100 cm × 100 cm** rectangular environment
- **5 cm × 5 cm** spatial bins
- **30 × 20** spatial bins
