# BIO-324: Spatial Firing-Rate Maps

A hands-on tutorial on generating spatial firing-rate maps from spike and position data collected in the laboratory.

## Open in Google Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/namhsuya/spacelab-stuff/blob/main/bio-324-ratemap-v4.ipynb)

Click the badge above to open the tutorial directly in Google Colab.

Once opened, select **File → Save a copy in Drive** and work through the notebook.

## What you will learn

- Position and spike data
- Spatial binning
- Occupancy calculation
- Spike counting
- Spatial firing-rate maps
- Gaussian smoothing

## Prerequisites

No prerequisites are required. Some familiarity with Python is helpful, but prior Python experience is **not mandatory**.

## Example environment

- **180 cm × 120 cm** rectangular environment
- **5 cm × 5 cm** spatial bins
- **36 × 24** spatial bins
